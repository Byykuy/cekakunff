    Tentang

    Cek UID FF menampilkan profil akun Free Fire dari UID yang kamu masukkan. Data diambil dari API pihak ketiga, lalu ditampilkan dalam satu kartu yang mudah dibaca.

    Yang ditampilkan

    • Nickname, UID, server, dan level
    • Peringkat Battle Royale dan Clash Squad
    • Klan, pet, skor kredit, Booyah Pass
    • Tanggal akun dibuat dan login terakhir

    Yang tidak dilakukan

    Situs ini tidak meminta password, tidak meminta login, dan tidak bisa mengubah apa pun di akun game.

    Kebijakan privasi

    UID yang kamu ketik dikirim ke server situs ini, lalu diteruskan ke penyedia API untuk mengambil data profil. Situs ini tidak membuat akun pengguna dan tidak menyimpan UID di database.

    Disimpan di perangkatmu

    Lima UID terakhir dan pilihan mode gelap atau terang disimpan di browser kamu (localStorage). Datanya tidak dikirim ke mana pun dan hilang kalau data browser dihapus.

    Pihak ketiga

    Penyedia API menerima UID yang kamu cek dan punya kebijakannya sendiri. Font dimuat dari Google Fonts.
